# خدمة عروض واتساب الأعمال (WhatsApp Offers)

خدمة صغيرة تستقبل رسائل عملائك عبر **WhatsApp Cloud API** الرسمي من Meta،
وتُرسل لهم رسائل العروض **بطريقة قانونية** تحمي رقمك من الحظر.

> ⚠️ **قاعدة أساسية:** خارج نافذة الـ24 ساعة من آخر رسالة للعميل، لا يُسمح بإرسال
> رسائل تسويقية إلا عبر **قوالب معتمدة** من Meta، و**فقط لمن وافق صراحةً** على استقبال العروض.
> لذلك الخدمة تطلب موافقة العميل أولًا (Opt-in) ثم ترسل له العروض.

---

## الخطوات من الصفر

### 1) تجهيز حساب Meta
1. أنشئي حسابًا على <https://developers.facebook.com> وأضيفي تطبيقًا من نوع **Business**.
2. أضيفي منتج **WhatsApp**، ستحصلين على:
   - **Access Token** (توكن مؤقت للتجربة، ثم توكن دائم للإنتاج)
   - **Phone Number ID**
   - رقم تجربة مجاني (ثم أضيفي رقمك الحقيقي لاحقًا)

### 2) إعداد المشروع
```bash
cd whatsapp-offers
npm install
cp .env.example .env
```
ثم افتحي `.env` واملئي: `WHATSAPP_TOKEN`، `PHONE_NUMBER_ID`، و`VERIFY_TOKEN` (نص سري من اختيارك).

### 3) تشغيل الخادم
```bash
npm start
```
الخادم يستمع على `/webhook`. لتجربته من الإنترنت استخدمي نفقًا مثل:
```bash
npx localtunnel --port 3000
```
أو انشريه مجانًا على Render / Railway.

### 4) ربط الـWebhook في Meta
في إعدادات WhatsApp > Configuration:
- **Callback URL**: `https://<عنوانك>/webhook`
- **Verify Token**: نفس قيمة `VERIFY_TOKEN`
- فعّلي حقل **messages**.

## كيف تُرسلين العروض للأرقام القديمة (بأمان)

### أ) استيراد الأرقام القديمة
ضعي الأرقام في ملف نصي (رقم دولي بدون + في كل سطر، مثل `9665xxxxxxxx`):
```bash
node scripts/import-numbers.js numbers.txt
```

### ب) إنشاء قالب "إعادة التفعيل" في Meta
من WhatsApp > Message Templates، أنشئي قالبًا مصنّفًا **Marketing** باللغة العربية، مثال:

> مرحبًا 👋 شكرًا لتواصلك معنا سابقًا. هل ترغب باستقبال عروضنا وخصوماتنا الحصرية؟
> [زر: نعم، أرسلوا لي العروض] [زر: لا، شكرًا]

انتظري اعتماده من Meta (دقائق إلى ساعات).

### ج) إرسال قالب إعادة التفعيل
```bash
node scripts/send-reactivation.js <اسم_القالب>
```
يُرسل فقط لمن لم يحسم موافقته بعد. ردّ العميل (نعم/لا) يُسجَّل تلقائيًا عبر الخادم.

### د) إرسال العرض للموافقين فقط
أنشئي قالب العرض (Marketing)، مثال فيه متغيّرات: «خصم {{1}} حتى {{2}}»، ثم:
```bash
node scripts/send-offer.js <اسم_القالب> "20%" "نهاية الأسبوع"
```
يُرسل **فقط** لمن حالته `yes`.

### مراجعة القائمة
```bash
node scripts/list-contacts.js
```

## الأوامر باختصار
| الأمر | الوظيفة |
|---|---|
| `npm start` | تشغيل خادم استقبال الرسائل |
| `node scripts/import-numbers.js file.txt` | استيراد أرقام قديمة |
| `node scripts/send-reactivation.js NAME` | طلب الموافقة من غير المحسومين |
| `node scripts/send-offer.js NAME [متغيرات]` | إرسال العرض للموافقين |
| `node scripts/list-contacts.js` | ملخّص الأرقام والموافقات |

## ملاحظات مهمة
- **التكلفة**: الاستقبال والرد خلال 24 ساعة شبه مجاني؛ رسائل القوالب التسويقية مدفوعة لكل رسالة
  (راجعي <https://developers.facebook.com/docs/whatsapp/pricing>).
- **الحماية من الحظر**: لا تُرسلي عروضًا لمن لم يوافق. احترمي زر الإيقاف دائمًا.
- **التخزين**: الأرقام تُحفظ في `data/contacts.json` (غير مُدرج في Git). للإنتاج يُفضّل قاعدة بيانات.
- هذه الخدمة تستخدم الواجهة الرسمية فقط، ولا تعتمد على أتمتة تطبيق واتساب العادي (وهو ممنوع).

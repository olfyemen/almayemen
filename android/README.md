# حقيبة الما 🧰

تطبيق أندرويد (Kotlin + Jetpack Compose) يجمع أدوات يومية، كل أداة يمكن إضافتها اختصاراً إلى الشاشة الرئيسية
(ضغطة مطولة على الأداة أو زر 📌)، وأهمها أيضاً في قائمة الضغط المطوّل على أيقونة التطبيق.

| الأداة | أبرز ما فيها |
|---|---|
| ⏰ التنبيه الدوري | أيام الأسبوع، من ساعة إلى ساعة (حتى بعد منتصف الليل)، كل N دقيقة، نغمة واهتزاز، تنبيهات متعددة |
| 🔕 الصامت المجدول | أوقات محددة، أوقات الصلاة (قبل/بعد الأذان)، صلاة الجمعة، صامت أو اهتزاز، يعيد الوضع السابق تلقائياً، مواقيت تُحسب بدون إنترنت بسبع طرق + تعديل يدوي |
| 🔁 التنبيه المتكرر | مرة واحدة/دقائق/ساعات/يومي/أيام محددة/أسبوعي/شهري/سنوي، ساعات عمل، ينتهي بتاريخ أو بعدد، تذكير مسبق، غفوة، منبه بملء الشاشة |
| 🍅 بومودورو | تركيز/استراحة قصيرة/طويلة، بدء تلقائي، عدّاد في الإشعارات، إحصائية اليوم |
| 📒 سجل الحسابات | مجموعات (حساب أم) ← حسابات ← عمليات له/عليه، عدة عملات، إدخال سريع بتاريخ اليوم وجمع مثل 500+250، إرسال آخر عملية والرصيد أو كشف PDF عبر واتساب/SMS لرقم صاحب الحساب أو رقم آخر، نسخ احتياطي |
| 📲 نقل الملفات | إرسال ملفات ومجلدات لأي هاتف على نفس الواي فاي أو الهوتسبوت (مع قبول/رفض)، غرف دردشة مفتوحة أو بكلمة سر لتبادل الرسائل والملفات والمجلدات، دخول من المتصفح لمن ليس عنده التطبيق (رابط/QR)، هوتسبوت سريع برمز QR، الحفظ تلقائياً في التنزيلات/حقيبة الما، والملفات المؤقتة تُحذف عند الإغلاق |
| 📱 فحص الهاتف | 18 فحصاً للعتاد، كل الحساسات لحظياً (أرقام/مخطط/أشرطة/عدّاد)، البطارية، معلومات الجهاز |
| 🚀 سرعة الإنترنت · 📶 قوة الإشارة · 🌙 التاريخ الهجري · 🔳 QR · 📡 مورس | |

## البناء

```bash
cd android
./gradlew :app:testDebugUnitTest :app:assembleRelease
```

الناتج: `app/build/outputs/apk/release/app-release.apk` (أندرويد 8 فما فوق).
يُبنى أيضاً تلقائياً في GitHub Actions عند أي تعديل داخل `android/`.

ملاحظة: مفتاح التوقيع `app/alma.keystore` محفوظ في المستودع حتى تُثبَّت التحديثات فوق النسخة السابقة دون حذفها.
إن أردت نشره على متجر Google Play فأنشئ مفتاحاً خاصاً ولا تضعه في المستودع.

# رسائل المستخدمين إلى جدول Google

1. افتح جدول «رسائل حقيبة الما» في Google Drive.
2. من القائمة: **الإضافات ← Apps Script**.
3. احذف ما في المحرر والصق محتوى الملف `apps-script.gs` ثم احفظ (Ctrl+S).
4. **نشر ← نشر جديد ← (رمز الترس) تطبيق ويب**:
   - التنفيذ باسم: **أنا**
   - من يمكنه الوصول: **أي شخص**
   ثم «نشر»، ووافق على الأذونات (الجدول والبريد).
5. انسخ «رابط تطبيق الويب» (ينتهي بـ `/exec`).
6. ضع الرابط في الملف `android/app-config.json` على فرع **main** في GitHub:
   ```json
   { "feedbackUrl": "https://script.google.com/macros/s/....../exec" }
   ```
   (يمكن تعديله من موقع GitHub مباشرة بزر القلم.) يقرأه التطبيق تلقائياً بلا حاجة لإصدار جديد.

تُحفظ كل رسالة صفاً في الجدول ويصلك بها بريد على بريد صاحب الجدول. الرسائل التي تُكتب بلا إنترنت تُحفظ في الهاتف وتُرسل لاحقاً.

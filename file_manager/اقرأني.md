# الما — مدير الملفات على الشبكة المحلية

**إعداد م/ماهر العلفي / 00967777408089** · جميع الحقوق محفوظة ©

برنامج لإدارة الملفات يعمل بالبايثون وتفتحه من المتصفح، على الكمبيوتر نفسه أو من أي جوال أو كمبيوتر متصل بنفس الشبكة (الواي فاي).
فيه أدوات كثيرة تسرّع العمل على الملفات.

---

## التشغيل

### الطريقة السهلة
- **ويندوز:** شغّل ملف `تشغيل-ويندوز.bat` بنقرتين.
- **لينكس / ماك:** شغّل `./تشغيل-لينكس-ماك.sh`

في أول تشغيل يثبّت البرنامج المكتبات المطلوبة بنفسه، ثم يعرض روابط مثل:
```
http://localhost:8000
http://192.168.1.5:8000   ← افتح هذا من الجوال
```

### يدوياً
```bash
pip install -r requirements.txt
python app.py                                   # يشارك مجلد المستخدم
python app.py --root "D:/ملفاتي"                 # مجلد محدد
python app.py --root "الصور=D:/Photos" --root "العمل=E:/Work"   # أكثر من مجلد مع أسماء
python app.py --password 1234                   # حماية بكلمة مرور (مستحسن)
python app.py --port 9000                       # تغيير المنفذ
python app.py --readonly                        # قراءة وتنزيل فقط بدون تعديل
```
ويمكن وضع الإعدادات في ملف `config.json` (انسخه من `config.example.json`).

### أدوات الفيديو تحتاج ffmpeg
- ويندوز: `winget install ffmpeg`
- لينكس: `sudo apt install ffmpeg`
- ماك: `brew install ffmpeg`

## المميزات

### إدارة الملفات
- تصفح بعرض **قائمة** أو **شبكة صور مصغرة** (للصور والفيديو)، ووضع ليلي.
- رفع ملفات أو **مجلدات كاملة** بالسحب والإفلات مع عرض التقدم والسرعة.
- تنزيل ملف، أو تنزيل عدة ملفات أو مجلد كملف ZIP.
- نسخ / قص / لصق، ونقل أو نسخ إلى مجلد آخر، وسحب الملفات وإفلاتها على مجلد.
- **سلة محذوفات** يمكن الاسترجاع منها، و**تراجع (Ctrl+Z)** عن إعادة التسمية والنقل والتنظيم.
- معاينة الصور والفيديو والصوت و PDF، و**محرر نصوص** مدمج.
- المفضلة، والتصفية السريعة، والفرز حسب الاسم أو الحجم أو التاريخ أو النوع.
- خصائص الملف (الأبعاد، مدة الفيديو، الترميز...) وبصمة MD5 و SHA-256 مع المقارنة.
- ضغط ZIP وفكّه، مع إصلاح الأسماء العربية في الملفات المضغوطة القديمة.

### ✏️ إعادة التسمية دفعة واحدة (مع معاينة قبل التطبيق)
قواعد تضيفها فوق بعض وترتّبها كما تريد:
- بحث واستبدال (نص عادي أو تعبير نمطي Regex).
- إضافة نص في البداية أو النهاية أو في موضع معيّن.
- حذف أحرف أو الإبقاء على أول/آخر عدد منها.
- **ترقيم تسلسلي** (001، 002...) بأرقام إنجليزية أو عربية.
- إضافة **التاريخ**: تاريخ التعديل أو **تاريخ التصوير من EXIF** أو تاريخ اليوم.
- **قالب مخصص** مثل `{parent}_{n:3}_{date:%Y%m%d}_{w}x{h}`.
- تنظيف الأسماء: المسافات، الرموز، الأقواس، **حذف التشكيل**، توحيد الألف والتاء المربوطة، تحويل الأرقام العربية، **تحويل العربي إلى حروف لاتينية**.
- تغيير حالة الأحرف والامتداد.
- **حفظ القواعد كقالب** لاستخدامها لاحقاً.

### 🗂️ التنظيم والفرز التلقائي
توزيع الملفات على مجلدات حسب: النوع، الامتداد، السنة، الشهر، اليوم، الحجم، الحرف الأول، كلمات في الاسم (مثلاً «فاتورة» إلى مجلد فواتير)، اتجاه الصورة (أفقي أو عمودي)، أو تقسيمها إلى مجلدات بعدد ثابت.
وفيه أيضاً **التسطيح**: إخراج كل الملفات من المجلدات الفرعية. كل ذلك مع معاينة قبل التنفيذ وإمكانية التراجع.

### 📊 تحليل المساحة / الأكبر حجماً
الحجم الكلي، و**أكبر 200 ملف** مع إمكانية حذفها مباشرة، وأحجام المجلدات الفرعية، والتوزيع حسب النوع والامتداد والسنة.

### 🔎 البحث المتقدم
بالاسم أو Regex، والنوع، والامتداد، والحجم الأدنى والأقصى، والتاريخ، و**البحث داخل محتوى الملفات النصية**، مع إجراءات جماعية على النتائج.

### 👯 الملفات المكررة
يقارن محتوى الملفات بالبصمة فيكون دقيقاً، ويعرض المساحة المهدرة، وفيه تحديد تلقائي «الكل ماعدا الأقدم أو الأحدث» ثم الحذف إلى السلة.

### 🖼️ الصور
- تصغير الصور: حسب الضلع الأطول، أو الاحتواء داخل أبعاد، أو نسبة مئوية، أو أبعاد محددة، أو قص وتوسيط.
- تحويل الصيغة إلى JPG أو **WebP** أو PNG أو ICO...، مع تحديد الجودة أو **حجم مستهدف بالكيلوبايت**.
- تدوير وقلب، أبيض وأسود، وتحسين التباين.
- **علامة مائية نصية**.
- قوالب جاهزة مثل «واتساب» و«ويب» و«أقل من 200KB».
- **دمج الصور في ملف PDF**، و**لوحة صور مجمعة**.

### 🎬 الفيديو (ffmpeg)
- **ضغط الفيديو** مع اختيار الدقة (4K حتى 240p) والجودة CRF والترميز H.264 أو **H.265**.
- تحويل إلى MP4، و**استخراج الصوت** بصيغة MP3 أو M4A أو WAV، وتحويل إلى **GIF**.
- استخراج لقطات، وإزالة الصوت، و**قص مقطع**، وتدوير، وتسريع أو إبطاء.
- **دمج عدة فيديوهات** في فيديو واحد.
- نسبة التقدم تظهر في لوحة المهام، ويمكن الإلغاء في أي وقت.

### 🏷️ البيانات الوصفية (الكتابة داخل الملف نفسه)
- **الصور:** الفنان، حقوق النشر، الوصف، العنوان، الكلمات المفتاحية، التعليق، تاريخ التصوير. تدعم العربية، وتظهر في خصائص الملف في ويندوز، وتُكتب في JPEG **بدون إعادة ضغط** فلا تقل الجودة.
- **الصوتيات (MP3...):** العنوان، الفنان، الألبوم، السنة، النوع...
- **PDF:** العنوان، المؤلف، الموضوع، الكلمات المفتاحية.
- **الفيديو:** العنوان، الوصف، التعليق...
- تعديل جماعي مع المتغيرات `{name}` و`{n}` و`{parent}`.
- **حذف كل البيانات الوصفية** (بما فيها موقع GPS) لحماية الخصوصية قبل مشاركة الملفات.

### أدوات أخرى
- 📅 **تعديل تواريخ الملفات**: من تاريخ التصوير، أو من الاسم، أو تاريخ تحدده.
- 📝 **أدوات النصوص**: بحث واستبدال داخل عدة ملفات، إضافة سطر في البداية أو النهاية، حذف الأسطر الفارغة أو المكررة، ترتيب الأسطر، تحويل الترميز (يصلح ملفات الترجمة SRT العربية التي تظهر رموزاً غريبة)، ودمج الملفات.
- 📕 **أدوات PDF**: دمج، تقسيم، استخراج صفحات أو حذفها، تدوير، ضغط، حماية بكلمة مرور، واستخراج النص.
- ⚖️ **مقارنة مجلدين** ومزامنتهما (نسخ الملفات الناقصة).
- 🧹 **حذف المجلدات الفارغة**.
- 📋 **تصدير قائمة الملفات** إلى Excel (CSV).

## ملاحظات أمان
- البرنامج لا يصل إلا إلى المجلدات التي تحددها بـ `--root`.
- **استخدم كلمة مرور** (`--password`) إذا كانت الشبكة يتصل بها أشخاص آخرون.
- استخدمه على الشبكة المنزلية أو شبكة العمل فقط، ولا تفتحه على الإنترنت.
- الملفات المحذوفة تُنقل إلى مجلد مخفي اسمه `.alma_trash` داخل كل موقع، إلى أن تفرغ السلة.

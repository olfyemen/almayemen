# almayemen — أدوات الما

كل أداة في مجلد خاص بها. الصفحة الأولى (`index.html`) قائمة فيها زر لكل أداة.

| المجلد | الأداة | الرابط |
|---|---|---|
| `alma/` | **الما** — تبادل الملفات بين الجوالات والكمبيوتر عبر المتصفح، ومعه أدوات PDF بدون إنترنت | https://olfyemen.github.io/almayemen/alma/ |
| `invoices/` | **ماسح الفواتير** — يصوّر 4 فواتير يدوية في اللقطة ويقرأ رقم كل فاتورة الأحمر ومبلغها، ويصدّرها لـ Excel | https://olfyemen.github.io/almayemen/invoices/ |
| `sahifa/` | **الصحيفة السجادية اليومية** — دعاء اليوم، وموضوع وقصة وحكمة لكل يوم من الشهر الهجري، وفهرس الصحيفة | https://olfyemen.github.io/almayemen/sahifa/ |

## ملاحظات
- تعليمات «الما» وأدوات PDF والحماية بالرمز في `alma/اقرأني.txt`. أداتا الختم والتحقق (`اختم-الحماية.py` و`تحقق-الحماية.py`) في نفس المجلد، لأنهما تبحثان عن الملفات بجانبهما.
- الروابط القديمة (`pdf.html` و`sahifa.html`) تتحوّل تلقائياً للمكان الجديد عن طريق `404.html`.
- من ثبّت «الما» كتطبيق قبل هذا الترتيب يفتح له التطبيق القديم قائمة الأدوات. لتطبيق مباشر: يفتح `alma/` ويثبّته من جديد.
- ماسح الفواتير يحتاج مفتاح Claude API (من console.anthropic.com)، والكاميرا المباشرة تحتاج فتحه من رابط https.

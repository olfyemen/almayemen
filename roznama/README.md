# الروزنامة الهجرية اليومية

افتح الملف `roznama.html` في متصفح الجوال أو الكمبيوتر — يعمل بدون إنترنت (الخطوط الجميلة فقط تحتاج إنترنت).

- يفتح على يوم اليوم تلقائيًا (التاريخ الهجري وفق أم القرى + الميلادي).
- الأيام الماضية مفتوحة للقراءة، والأيام القادمة مقفلة مع حكمة «لا تستعجل الغد».
- التنقل: الأزرار في الأسفل، أو سحب الصفحة، أو أسهم لوحة المفاتيح.
- عرض يومي / أسبوعي / شهري.
- كل يوم: حكمة من تراث العالم، حديث أو أثر، قصة تراثية، كلمة تحفيزية، مناسبات وأحداث،
  ثلاث كلمات إنجليزية، وثلاث كلمات متقاربة للآيلتس مع شرح الفرق.
- «المزيد»: أحداث الشهر، تحدّي اليوم، سؤال للتأمل، ذكر، ودفتر يوميات يُحفظ في المتصفح.
- الإعدادات: تعديل التاريخ الهجري ±يوم، الوضع الليلي، حجم الخط.

مجلد `parts/` هو مصدر الملف؛ لإعادة بنائه:
`cat parts/1-head.html parts/2-data-a.js parts/3-stories.js parts/4-english.js parts/5-app.js > roznama.html`
